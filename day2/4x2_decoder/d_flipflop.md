The D (Data) Flip-Flop is a streamlined, fundamental sequential logic memory element. It improves upon the SR flip-flop by completely eliminating the possibility of an "invalid" or "restricted" state.At every positive edge of the clock signal, the flip-flop captures the value currently present on the Data (d) input and holds it on the output (q) until the next clock edge.Portsinput clk: Clock signal (triggers on the positive/rising edge).input d: Data input (the value to be stored).output reg q: The main stored memory bit.output q_bar: The inverted output (~q).Truth Table (Behavior at Positive Clock Edge)d (Data Input)q (Next State Output)Description00Stores a Logic 011Stores a Logic 1
